# Apart Swarm Alignment Hackathon (Nov 2026)

Entry workspace for the [Swarm Alignment Hackathon](https://apartresearch.com/sprints/swarm-alignment-2026), run by [Apart Research](https://apartresearch.com) with AI Alignment Foundation and AE Studio.

## About the event
- **When:** Friday 6 to Sunday 8 November 2026, online.
  - **Start:** Fri 6 Nov 2026 (IST). The page gives no start time yet; this will be updated when it does.
  - **End (submission deadline):** Sun 8 Nov 2026, 11:59 PM AoE = **Mon 9 Nov 2026, 5:29 PM IST**.
  - Times in this repo are IST unless marked AoE.
- **Theme:** safety of multi-agent ("swarm") AI systems: how groups of AI agents coordinate, how that can go wrong, and how to study, contain and oversee them.
- **Tracks:** Sandboxes and Testbeds; Science of Agent Networks; Agent Infrastructure; Multi-Agent Oversight and Control.
- **Output:** a short research report (PDF) on the official template, plus optional code and demo.
